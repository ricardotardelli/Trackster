# Trackster Corporate Site

This package contains a standalone Angular corporate website for Trackster.

## Routes

- `/`
- `/platform`
- `/use-cases`
- `/about`
- `/contact`
- `/privacy`

## Main CTA

The primary call to action points to:

- `https://studio.trackster.pt`

## Contact form

The contact page uses a `mailto:` flow so it works immediately without a backend.

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
